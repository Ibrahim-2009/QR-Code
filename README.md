## QR-Code
QR-Code Frontend Mentor Challenge

## 🚀 Overview

This project is a solution to a Frontend Mentor challenge. The goal was to build a responsive QR code card with a clean and modern layout.

## 🛠️ Built With

* HTML5: semantic structure
* CSS3: Flexbox for layout
* CSS: variables for consistent colors
* Google Fonts: Outfit Font

## 🎯 Features

* Centered layout using Flexbox
* Minimal and clean UI design
* Reusable CSS variables
* Good spacing and typography

## 📚 What I Learned

* How to center elements using Flexbox
* Using CSS variables to manage design consistency
* Improving UI with proper spacing and font choices
